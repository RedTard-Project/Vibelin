# Сообщения с подстановкой. Пробуются по порядку, только если точного
# совпадения в fragments.txt не нашлось, — первый сработавший выигрывает.
#
# Формат:  регулярка = шаблон
#
# Разделитель — первое вхождение " = " (с пробелами). В регулярках пробелов
# вокруг "=" не бывает: (?=...) и (?<=...) пишутся слитно, так что это безопасно.
#
# Экранировать ничего не нужно: \d, \. и кавычки пишутся как есть.
#
# В шаблоне:
#   $1, $2 ...  — захваты регулярки
#   $2|acc      — захват, склонённый в падеж: ищется сначала в nouns.txt,
#                 затем в склонениях персонажа; если нигде нет — остаётся как есть
#   падежи: nom gen dat acc ins pre
#
# Регулярка применяется к ОДНОЙ текстовой ноде, уже без краевых пробелов.
# Поэтому имя, обёрнутое в <b>, в захват не попадает — см. "dodges" ниже.
#
# ПОРЯДОК — ЧАСТНОЕ ПЕРЕД ОБЩИМ. "^(.+?) slashed (.+?)!$" радостно поймает
# "I'm slashed by X!" и выдаст "I'm рубит by X!", если стоит выше.

# --- удары по себе и получение удара (строго выше общих!) ---

^(.+?) (?:slashed|stabbed|cut|clawed|struck|punched|chopped|bashed|whacked|smashed|sliced|whipped|slapped|kicked|bit) themself!$ = $1 ранит себя!
^I (?:slash|stab|cut|claw|strike|punch|chop|bash|smash|kick|bite) myself!$ = Я раню себя!
